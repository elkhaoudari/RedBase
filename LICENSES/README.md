# License notices

RedBase uses file-level licensing. There is intentionally no single repository-wide `LICENSE` file because different parts of the repository use different licenses and third-party material may retain its own terms.

## Original RedBase material

- Original documentation and knowledge articles: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/legalcode).
- Original scripts, utilities, schemas, and validation code: [MIT License](https://opensource.org/license/MIT).

Unless a file or directory says otherwise, apply the relevant default above according to the file type. Each contribution must preserve its license/provenance metadata where applicable.

## Third-party material

Third-party content is **not** automatically relicensed under either default. Follow its original license, attribution, and redistribution requirements. If permission to redistribute is unclear, link to the source instead of copying it.

SPDX identifiers used in metadata:

- `CC-BY-4.0`
- `MIT`

See `docs/licensing-policy.md` and `NOTICE` for the full policy and attribution register.
