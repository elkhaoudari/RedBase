# Research and Sourcing Guide

Preferred source classes:
- Standards and guidance: OWASP, CWE, relevant protocol specifications.
- Research: peer-reviewed security papers and original researcher publications.
- Training and technical references: PortSwigger Web Security Academy and documented security research.
- Public disclosures: coordinated vulnerability disclosures and public bug bounty reports.
- Maintained tools and corpora: use as discovery references; check each repository's license before importing content.

Avoid:
- unattributed paste dumps;
- scraped private communities;
- paid exploit marketplace content;
- credentials, secrets, or personal data;
- content whose origin or redistribution rights cannot be established.

For every adapted item, preserve attribution and license requirements. A public URL is not automatically a redistribution license.
