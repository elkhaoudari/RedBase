# Licensing and Attribution Policy

RedBase uses mixed licensing according to the type and provenance of each contribution.

Proposed defaults for original RedBase work:
- Original documentation: CC BY 4.0.
- Original scripts and utilities: MIT.
- Original schemas and validation code: MIT.

Third-party material:
- Retain the original license where redistribution is permitted.
- Do not relicense third-party content as RedBase-owned material.
- Record source URL, title, author/project, license, and required attribution.
- If adapted, set `source: adapted` and populate `adapted_from`.
- If license compatibility or redistribution rights are unclear, link to the source instead of copying its content.

A repository-level license does not override file-level third-party licenses. Keep `NOTICE` current.

Payload records follow the documentation/provenance rules in
`docs/payload-standard.md`. A record marked `pending-policy-review` is provisional
and must have its license resolved before release; this value is not a license.
