# Security Policy

RedBase is a documentation and reference repository.

Do not submit:
- credentials, tokens, private keys, personal data, or other secrets;
- target-specific exploit instructions against systems without authorization;
- claims of a working zero-day or unpatched exploit as a payload collection entry;
- malware, destructive tooling, or automated exploitation against third-party targets.

Report repository security issues privately to the maintainers through the contact method listed in the GitHub repository settings.
